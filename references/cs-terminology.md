# CS:GO / CS2 解说术语与点位对照

解说音频里 80% 的误译来自两类词：**地图点位名** 和 **经济/战术术语**。
点位名在中文解说中通常**保留英文原词**（jungle、banana、connector），不要硬译成"丛林/香蕉道"以外的怪词。

## 五、纠错原则

1. **先定背景再纠错**：不知道是哪场比赛，就无法判断 `zelex` 还是 `Alex`。
2. **人名优先服从当期名单**：同一段音频里反复出现的名字必须全场统一。
3. **无法确认时标存疑**：用 `【?】` 标注并在交付说明里列出，不要编一个看起来合理的名字。
4. **比分数字不改写**：`14-0` 不能译作"14 平"，`35-20` 是总击杀数而非比分。
