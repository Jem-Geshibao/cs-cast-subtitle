# 双语对照字幕的排版与翻译风格

支持**两种抖音排版模式**，同一份校对稿可按需要生成横屏版或竖屏版。
模式由 `scripts/layouts.py` 统一定义，用 `--layout landscape|portrait` 切换；**必须先选定模式再排版**，不要混用两套规则。

## 零、模式对比（先看这个）

| | `landscape` 横屏（默认） | `portrait` 竖屏 |
|---|---|---|
| 单块结构 | 源语言 1 行 + 中文 1 行，**共 2 行，不许折行** | 源语言 ≤3 行 + 中文 ≤2 行，**允许折行** |
| 纯中文段 | **1 行** | ≤2 行 |
| 加权行宽上限 | **48**（中文 ≈25 字 / 英文 ≈48 字符） | **46**（中文 ≈19 字 / 英文 ≈46 字符） |
| 超宽处理 | **精简文字**（不许换行、不许改时间轴） | 在逗号/连词处**断行**（仍不改时间轴） |
| 样例 | `assets/example_bilingual.srt` | `assets/example_bilingual_portrait.srt` |

行宽估算统一为「CJK/全角权重 1.9，其他权重 1」，由 `build_srt.py` / `validate_srt.py` 自动体检；阈值可用 `--limit` / `--max-lines` 覆盖。

## 一、通用规则（两种模式都适用）

```
<序号>
HH:MM:SS,mmm --> HH:MM:SS,mmm
源语言（小写）
中文
```

- **时间轴严禁改动**：必须使用 ASR 原始 start/end。宁可精简或断行，也不要合并或拆分时间块、不要改时间戳。
- 源语言行**全小写**；中文解说/采访段**只输出中文**，不做双语对照；静音段不输出。
- 已确认的选手 ID、战队名、地图点位不翻译。
- 无法确认的人名标 `【?】` 并在交付说明里列出，**禁止编造**。

## 二、横屏模式（landscape）：安全区 + 单行

**两条最硬的约束**：字幕不可超出安全区；一段只允许两行（源 1 + 中 1），任何一行都不许再折行。

### 安全区（16:9）

| 位置 | 预留 | 被遮挡内容 |
|---|---|---|
| 左右两侧 | 各 ≈ 8% | 裁切风险、右侧互动按钮 |
| 底部 | ≈ 12% | 进度条、播放控件 |
| 顶部 | ≈ 10% | 标题、作者栏 |

有效宽度约为画面宽度的 **84%**，字幕置于底部安全区之上。行宽 48 是**保守值**；若模板字号不同，用 `--limit` 调整并**真机导出确认**。

### 单行化与精简（不能换行怎么办）

顺序固定：

1. **先合并**：把校对稿里的软换行合并成一行（英文用空格连接，中文直接连接）。`build_srt.py` 在横屏模式下自动完成。
2. **再测宽**：`validate_srt.py` 报超宽才进入第 3 步。
3. **最后精简**（按此优先级，不要一步到位删信息）：
   - 删重复的强调词：`absolutely beautiful, absolutely beautiful` → 保留一次
   - 删解说垫话：`well`、`you know`、`I mean`、`like`
   - 压缩修饰：`it is just another round from him` → `another round from him`
   - 去掉英文行末尾从句，保留主句信息
   - 中文行去口水词：`这个`、`那个`、`的话`、`其实`
4. **仍超宽**：优先砍**源语言行**的次要成分（观众主要看中文），中文行保留完整信息；两条都压不进去才进一步压缩中文行。

## 三、竖屏模式（portrait）：多行 + 断行

- 单块最多 **5 行**（源语言 ≤3 + 中文 ≤2），建议 4 行以内，避免遮挡竖屏下半区的文案与互动区。
- 单行上限：加权宽度 ≤ 46（英文 ≈46 字符 / 中文 ≈19 字）。
- **超宽时在逗号/连词处断行**拆成两行，不要硬塞一行，也不要改时间轴。
- 中文行不要为了凑字数乱删信息；可在两行内讲完。

## 四、翻译风格（职业解说口吻）

1. **短句、动词强**：拿下、收下、轰出、撕开、架住、偷掉、打崩、稳拿、冲击。
2. **保留情绪**：`absolutely beautiful from donk` →「donk这波太漂亮了」；不要译成平铺直叙的书面语。
3. **不要过度意译**：解说信息（人数、方位、道具）必须准确传达，`four back towards CT` 必须译出"四人回防"。
4. **术语与 ID 不翻译**：点位名（jungle、short、connector、banana）、地图名、选手 ID、战队名保留原文。
5. **数字照抄**：比分 `14-0`、回合数直接保留，不换算、不改写。
6. **标点**：中文行用全角标点（，！？），**行尾不加句号**；源语言行保留原有轻量标点。
7. **中英混排不加空格**：`donk拉开距离`、`只要清掉jungle就行`，历史稿统一如此。
8. **第一人称**：英文解说的 `we / us` 通常指其支持的队伍，必要时译为"他们"。

## 五、一致性检查（交稿前必做）

- [ ] 已选定排版模式，且全文只遵循该模式规则
- [ ] 横屏：每段 ≤2 行（纯中文 1 行）、行宽 ≤48；竖屏：每段 ≤5 行、行宽 ≤46
- [ ] 同一选手 ID 全文写法统一（donk 不一会儿 Donk 一会儿 donk）
- [ ] 同一战队译名统一（TYLOO 一律"天禄"或直接保留 TYLOO）
- [ ] 同一点位译法统一（jungle 不一会儿"丛林"一会儿 jungle）
- [ ] 存疑项已在交付说明中列出（`【?】`），未混入字幕正文
- [ ] `validate_srt.py` 零报错

## 六、交付物命名与命令

- 字幕：`<原名>_bilingual_corrected.srt`
- 中间产物：`<原名>_segments.json`（主转写）、`_fill.json`（补录）、`_recheck.json`（攻坚重转）
- 生成：`python build_srt.py pairs.json out.srt --layout landscape|portrait`
- 校验：`python validate_srt.py out.srt --layout landscape|portrait`（**必须与生成时同模式**）
